## Answer key

| Q | Lesson | Answer | Why |
|---|---|---|---|
| 1 | 1 | B | Claude is guided by principles that help it avoid toxic or discriminatory outputs and illegal or unethical help, and behave as a safe and beneficial assistant. |
| 2 | 1 | C | 200K+ tokens is roughly 500 pages of text; up to 1M tokens is available on Pro, Max, Team and Enterprise with supported models. |
| 3 | 1 | D | Search handles standalone facts. A thinking partner is needed when personal context shapes the answer. The topic itself is not the deciding factor. |
| 4 | 1 | B | Claude Tag is the Slack integration. Claude Design builds interactive prototypes, Claude Code is the agentic coding tool, Claude for Microsoft 365 covers Excel, PowerPoint, Word and Outlook. |
| 5 | 2 | A | Set the stage (role, objective, context), define the task (the action), specify rules (style, tone, format, examples). Delegation/description/discernment belong to the 4D AI Fluency framework. |
| 6 | 2 | B | Sonnet balances capability and cost and is the recommended default. Opus is the largest model with hybrid reasoning, for the most complex tasks. |
| 7 | 2 | A | Changing the model results in a new chat. |
| 8 | 2 | C | On by default on Free, Pro and Max. On Team and Enterprise it is off by default and can be turned on in Settings > Memory once an organization Owner allows it. |
| 9 | 3 | D | Generic output usually means the prompt lacked context about your specific situation. |
| 10 | 3 | C | Discernment = evaluating quality, accuracy and appropriateness. Delegation = what goes to humans vs AI. Description = communicating with AI. Diligence = responsible, ethical use. |
| 11 | 3 | D | This is the delegation-diligence loop: test on a case where you know the right answer, evaluate gaps, refine, re-test. If Claude cannot match known results, the task may not be one to delegate. |
| 12 | 3 | A | Claude can occasionally produce plausible but incorrect information, especially for specific facts or niche topics. For high-stakes work, verify, ask for citations, use web search. |
| 13 | 4 | C | Multi-step work spanning your tools that runs on a schedule is a hand-off, which lives in Cowork (scheduled tasks). |
| 14 | 4 | D | Cowork gets local folder access and saves finished work into it. Chat can read what you upload but returns files as downloads. |
| 15 | 4 | A | Scheduled tasks generally run remotely (computer asleep or app closed is fine). A task that needs files on your computer runs locally, only while the app is open. |
| 16 | 4 | B | When the answer changes what you ask next, you are working turn by turn, which is Chat. |
| 17 | 5 | C | Project instructions guide tone, expertise level and response style in every chat in the project, alongside user preferences. |
| 18 | 5 | C | Projects scale using Retrieval Augmented Generation: Claude searches project files and pulls in only what is relevant, expanding capacity up to 10x. |
| 19 | 5 | A | Can view = read-only plus discussion rights. Can edit can modify instructions, update knowledge and manage members. The Owner controls everything. |
| 20 | 5 | D | Files uploaded during a chat stay separate from project knowledge. The project description is not seen by Claude directly. |
